# Hi, I'm Enes

I founded Buen. Most of my work is real estate visualization in Unreal Engine 5: interactive digital twins of housing projects that people can walk through before the building is finished. Around that I build my own tools in Houdini, 3ds Max and Python.

This is where I put the side projects I'm happy to share. [max-mcp](https://github.com/Kafkavari/max-mcp) lets an AI assistant work inside a running 3ds Max session while every change stays logged and undoable. [Gargantua](https://github.com/Kafkavari/gargantua) is a small GPU ray tracer that renders a looping black hole wallpaper.
